# 柱7 実カメラ測定プロトコル

合成劣化(`simulatePhoto`)で止まっている柱7 を、**実カメラ/実印刷/実スキャンの「測定された復元率」**に変えるための手順。
白書を「主張」でなく「測定」で語れるようにする、最高レバレッジの R&D。

> 役割分担: **キット(担体生成・測定)は Claude が用意済**。**撮影はあなたの物理操作**(Claude はカメラを操作できない)。
> 撮影後に一緒に復元率を測り、失敗の型を見てデコーダを実機向けに改良する。

---

## 手順

### 0. 担体を生成(repo ルートから)
```
node tools/real-camera/emit-carriers.mjs
```
→ `tools/real-camera/carriers/` に `p1-short.png` / `p2-prod.png` / `p3-long.png` + `manifest.json`。
（p1=小・p2=本番相当・p3=長文。N が大きいほど 1 モジュールが小さく、実カメラでの限界が見える。）

### 1. 表示 または 印刷
- **画面表示**: 担体 PNG を**全画面・最大輝度**で表示(画像ビューアの等倍/フィット。スケーリングのにじみは可)。ノングレア推奨。
- **印刷**: レーザープリンタ推奨、白余白を残して大きめ(例 A4 に 1 枚、10cm 角以上)。

### 2. スマホで撮影(1 担体あたり 5〜8 枚)
**担体が画面いっぱいに写るよう近づき、必ずピントを合わせる。** スマホの解像度なら px/module は十分(可読性バジェット §5.13 の床は楽に超える)。実機の本当の敵は**焦点・グレア・実レンズ歪み・照明勾配・斜め**。なので意図的にバリエーションを撮る:

| バリアント例(ファイル名サフィックス) | 狙い |
|---|---|
| `__straight` | 正対・順光(ベースライン) |
| `__tilt20` / `__tilt35` | 斜め 20°/35°(透視) |
| `__rot` | 担体を回転させて(全方位=キラリティ検証) |
| `__dim` / `__sidelight` | 暗め / 横からの光(照明勾配・影) |
| `__far` | 少し離れて(1 モジュール px を下げる=限界探り) |
| `__glare`(画面時) | わざと少し映り込み(グレア耐性) |

避けるもの: 手ブレ(ピンボケ)、担体が小さすぎる、極端なグレアで finder が消える。

### 3. ファイル名を付ける
`<carrierId>__<バリアント>.jpg`(例 `p2-prod__straight.jpg`, `p2-prod__tilt20.jpg`)。
prefix(`p2-prod`)が `manifest.json` の担体と一致していること。1 つのフォルダ(例 `photos/`)にまとめる。

### 4. JPEG → PNG 変換(コアは PNG・依存ゼロを保つため)
```
powershell -ExecutionPolicy Bypass -File tools/real-camera/convert-to-png.ps1 photos
```
→ `photos/` の `.jpg/.jpeg` を System.Drawing で `.png` に変換(追加依存なし)。

### 5. 測定
```
node tools/real-camera/measure.mjs photos
```
→ 写真ごとに `scanPhoto` で復元できたか(tip 一致 + 平文一致)、同一担体の複数枚を**フレーム融合**した結果、**単フレーム復元率**を表示。

---

## 結果の読み方と次の一手
- **✓ 復元+平文一致**: 実カメラでその条件は通った。
- **✗ PhotoError**: 媒体層で読めず(finder 不検出 / 補正破綻 / RS 訂正能力超過)。実機特有のギャップ。
- **✗ CordTamper**: デコードはできたがビット誤りが AEAD を割った(=復号の手前まで来ている)。

失敗の型と撮影条件(角度・距離・光)を突き合わせ、実機の主ギャップ(**JPEG ノイズ / 実レンズ歪み(§5.12 の射程超) / 照明勾配 / 焦点ボケ(§5.13 の PSF) / モアレ / 大きな実写中の担体局所化**)を特定して、`src/photo.js` を実機向けに改良する。これが「測定 → 改良」のループ。

> 注: `carriers/` と `photos/` は生成物・実写なので **git には入れない**(`.gitignore` 済)。
