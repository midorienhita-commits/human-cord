# 柱7 再印刷キット(印刷実写 第2テスト)

第1テスト(2026-06-16・実印刷15枚)の**失敗解剖**で確定したこと:

- **幾何層は実印刷を通過**(finder + キラリティリング + 自己クロック tick → 13/15 フレームで成立・N推定もほぼ実寸)。
- 落ちたのは **payload の RS 復号だけ**。原因は撮影/印刷側の物理2型:
  1. **プリンタ横バンディング**(全幅の黒バーが行を潰す)= **シート固定欠陥**なので**連写融合でも消えない**。
  2. **高密度モアレ**(モジュール過小で斜めエイリアシング)。
- ソース担体は完全に綺麗 → バーは**印刷で混入**。**デコーダは律速でない。印刷品質が律速。**

→ このキットは「**密度最小=モジュール最大**」+「**バンディングしない印刷**」で**まず1枚通す**ための再挑戦セット。

## 1. 印刷(ここが今回の主戦場)

バンディングを殺すのが最優先。効く順:

1. **レーザーで刷る。** 家庭用インクジェットの横スジ(ヘッド/紙送り由来)が第1テストの主犯。
   **コンビニのマルチコピー機(セブン/ローソン/ファミマ=ほぼレーザー)が最も確実で手軽**。
   セブンなら「ネットプリント」、ローソン/ファミマなら「PrintSmash / ネットワークプリント」で PNG をそのまま印刷。
2. **大きく刷る。** A4 に**1担体だけ**、**できる限り大きく**(目安 15〜18cm 角)。白余白はたっぷり残す。
   大きいほど 1 モジュールが大きく、バンディングの帯が相対的に細くなりモアレ周波数も下がる。
3. **品質は標準〜高品質**(ドラフト/エコノミー/トナーセーブは必ず OFF)。
4. **普通紙でよいがマット**。光沢紙はグレア(映り込み)が増えるので避ける。
5. 印刷したら**裸眼で横スジが無いか確認**。スジが見えたら刷り直し or 別プリンタ。

> ヒント: もし手元のプリンタでしか刷れず横スジが出るなら、担体を**90°回して**(横向き)刷ってみる。
> バンディングは紙送り方向に出るので、行と列のどちらに帯が乗るかが変わる。担体は4隅 finder+リングで
> 向きを自動補正するので、回しても復号に影響しない(ダメ元の無料実験)。

## 2. 撮影(1担体あたり 6〜8 枚の連写)

第1テストで幾何層は通っているので、**焦点・正対・均一光**だけ気をつければよい:

- **担体が画面いっぱい**に写るよう近づき、**必ずピントを固定**(タップして合焦ロック)。
- **正対**(斜めにしない)。机に平らに置き、真上から。
- **均一な拡散光**(窓の近くの日陰など)。直射・スポット光は照明勾配と影を作る。
- **グレア(映り込み)を避ける**。finder が光って消えると検出が落ちる。
- 同じ担体を**少しずつ角度・距離を変えて 6〜8 枚**(融合がモアレのランダム成分を相殺する)。

避けるもの: 手ブレ(ピンボケ)、担体が小さすぎる、強いグレア。

ファイル名は自由(measure は復号 tip で担体を自動判定)。1 フォルダにまとめる。

## 3. JPEG → PNG 変換
```
powershell -ExecutionPolicy Bypass -File tools\real-camera\convert-to-png.ps1 <写真フォルダ>
```

## 4. 測定(★ carriers-print を指定すること)
```
node tools/real-camera/measure.mjs <写真フォルダ> tools/real-camera/carriers-print
```
- 単フレーム復元率と、**同一担体バーストの融合**(連写→1復元)の両方が出る。
- 融合は measure.mjs が単フレーム成功>0 のときに走る。全敗でも融合を見たいときは:
  ```
  node tools/real-camera/fuse-bursts.mjs   # ただし対象は photos-print 固定(必要なら編集)
  ```

## 失敗したときの追加診断
```
node tools/real-camera/diag-binarize.mjs <写真.png>   # グローバルOtsu と 適応2値化を画像出力
node tools/real-camera/crop-zoom.mjs <写真.png> out.png 0.3 0.3 0.4 0.25 3  # 中央を拡大しバンド/モアレを目視
```

## 結果の読み方
- **✓ 復元+平文一致**: 印刷→復号が実測で通った = 白書に「測定された印刷復元」1点。**p0-min が通れば第一目標達成**。
- **✗ PhotoError**: まだ媒体層で読めず。`diag-binarize` で**横スジが残るなら印刷(プリンタ/サイズ)**、
  **斜めモアレなら密度(より短い担体 or より大きい印刷)**が次の調整軸。
- **✗ CordTamper**: あと一歩(デコードは成功・ビット誤りが AEAD を割った)= 融合枚数を増やすと届きやすい。
