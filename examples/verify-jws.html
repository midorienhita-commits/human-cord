公開検証(attestation v1)

発行者の公開鍵(JWKS)だけで、この証明が本物か・改ざんされていないかを確かめます。

// 証明の内容

仕組み: JWS(RFC 7515)の alg=EdDSA(RFC 8037)。ヘッダの kid(RFC 7638 サムプリント)で JWKS から鍵を選び、 BASE64URL(header).BASE64URL(payload) の Ed25519 署名を Web Crypto で検証します。payload の hc.facts が署名された事実です。 このページは採用先ごとの写しを必要としません。鍵は採用先が公開する JWKS(例: /.well-known/human-cord-keys.json)から取ります。
