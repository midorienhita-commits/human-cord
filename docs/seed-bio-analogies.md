## 0. 借りる層・借りない層(最重要の予防線)

生物の堅牢性は **物理ノイズに対する統計的・進化的** なもの。DNA には「計算で攻めてくる敵」がいない。
よって借りていいのは **担体・冗長・ライフサイクルの層(=「目」=物理層 robustness)** だけで、
**暗号的な約束の層(=「約束」=真正性・改ざん検知)** を生物の比喩で代用してはいけない。
約束は情報理論と物理という「変えられない根」から来る(計算非依存性の原則 / 三原則「AI と人は役割を分ける」)。
**比喩がこの境界を越えた瞬間が失敗境界柱の出番。** 以下の種はすべて「目」の層に属する。

## 1. relate() = 相同組換え修復(案件内の横断修復)  ✅ 実装済(2026-06-04)

**生物**: 二本鎖切断を、相同な無傷のコピー(姉妹染色分体)を鋳型に再建する(homologous recombination)。
壊れた鎖を、別に存在する正しいコピーから埋め戻す。

**示唆(柱3 の新しい使い道)**: 同一案件(docId)に複数の証明書/担体があるとき、それらを **相互の冗長コピー**
として扱う。1 枚が RS 訂正能力を超えて壊れても、同案件の別の 1 枚から **本質事実を再建** できる。
- いまの relate() は「同一案件を + で統合 / 別案件を − で差分」する**関連付け**機能。
  これを **横断修復(cross-document repair)** に拡張: 案件内の複数担体で多数決/再建する。
- RS(1 担体内の誤り訂正)の **一段上**の冗長 = 担体間の冗長。生物の「鎖内修復(校正/MMR)」と
  「鎖間修復(相同組換え)」の二段構えに対応。
- 注意: 修復は「目」の操作。再建後も各担体の AEAD(柱9)/発行者検査(柱4)は独立に効く(約束は不変)。

**実装 = `issue.js` の `reconstructCase(carriers, secret, {docId?})`(`npm run demo:reconstruct`・test/reconstruct.test.js 6 本)**:
- 各担体を発行者媒介 `verify` → intact / damaged(media-error/tamper)に分け、intact を docId でグループ化。
- **相同領域** = その案件の intact 姉妹すべてで一致する (key,value) = 再建された案件の本質事実
  (`recovered`)。`corroboration` = 相互検証した姉妹数。値が分かれるキーは `variable`(文書固有=非相同)。
- **非相同**(intact だが別 docId)は `foreign` に排除(取り違え/別案件検知)。**全滅**(無傷姉妹ゼロ)は `ok:false`。
- 正直な限界: 文書固有(非相同)フィールドは鋳型に無いので復元しない。再建は **verify 済みの真正な姉妹からのみ**
  = 偽の事実は混ざらない(媒体修復 ≠ 暗号的真正性は別ドメイン)。1 枚も残らなければ案件は失われる。

## 2. 動画フレーム ratchet = テロメア(不可逆な世代計数)  ✅ 実装済(2026-06-04)

**生物**: テロメアは複製のたび短縮し、Hayflick 限界で分裂を止める。
**複製回数を物理的に使い切る**内蔵カウンタ(無制限なコピーを禁じる)。

**示唆(柱5 ratchet / 鮮度・録画リプレイ耐性)**: 残 TODO の「動画フレーム ratchet」はテロメアそのもの。
- 担体を静止画でなく **フレーム鎖**にし、各フレームで ratchet を 1 チク消費(= テロメア 1 短縮)。
- 録画して後で再生(リプレイ)しても、鎖はすでに「短く」なっており **使い切られた世代**として弾く。
- 「生きた担体」= 複製のたび不可逆に状態が進む = テロメアの一方向性。柱8 煙で「使い切り済みの再提示」を上げる。
- これは**チャネル(その場限り)用**。長期保存文書(証明書)には鮮度窓を当てない既存方針と矛盾しない。

**実装 = `src/livecord.js`(依存ゼロ・`npm run demo:live`・test/livecord.test.js 9 本)**:
- `emitLive(message, secret, ctx, {startEpoch, frameMs, length})` → フレーム鎖(各フレーム=1 cord、平文に `{seq, prev=前フレーム tip}` を封入)。`length` = テロメア予算。
- `LiveVerifier(secret, {windowMs, length}).feed(frame, clock)` → 構造化 verdict(throw しない):
  `live` / `stale`(鮮度失効=後日再生)/ `spliced`(prev 鎖断裂=別録画接ぎ木)/ `reorder`(seq 不連続)/
  `tamper`(AEAD=改ざん/別発行者)/ `replay`(同一 tip 再提示)/ `exhausted`(予算超過)。
- **要(なぜ epoch を freshen できないか)**: `epoch` は公開軸だが `deriveCodebook` の salt に effく → 書き換えると
  codebook が変わり ratchet 鍵列が変わって AEAD が割れる(open が throw)。**epoch は実質 ciphertext に束縛**。
- **正直な限界**: 非対話では「鮮度窓内・別の検証者への即時リプレイ」は原理的に防げない(窓を frameMs 数個に
  絞れば実用上ほぼ封じる)。厳密な liveness はチャレンジ応答(検証者 nonce をその場で取り込む対話)
  = **`src/challenge.js` で実装済み**(2026-06-05)。検証者 nonce を応答の context に暗号束縛し、別検証者への
  即時リプレイを mismatch で弾く。残る限界は実時間中継(MITM relay)/距離詐称=距離限定の領分。

## 3. 二重らせんの「ひねり」= 視覚担体の構造モチーフ ★着目点

**生物**: 二重らせんは (a) 相補的二本鎖、(b) 右巻きの**キラリティ**、(c) 主溝/副溝の二経路、
(d) 塩基対合則(A-T/G-C)の制約アルファベット、(e) 規則的な周期(ひねりのピッチ)を持つ。
合成ゲノムに氏名・引用・誤り検査を埋めても生物が機能した実例もある(DNA ウォーターマーク)。

**示唆(柱7 担体 + 柱2 風景溶込み + 柱6 潜在チャネル)**: 「らせん」を担体の**構造モチーフ**にする。
- **相補二本鎖 = データ鎖 + 検査鎖**: 系統的符号(データ+パリティ)を、人間には「DNA 図」に見える
  有機担体(柱2)として描く。各鎖が相手の鋳型 = 視覚的に冗長。
- **キラリティ(右巻き/左巻き)で向きの曖昧性を破る** ← photo.js の急所への効き目。
  四隅が同一形の finder は面内回転 ±45° で向きが曖昧になる(現状の限界)。**らせんの巻き手は
  回転対称を持たない**ので、担体自身にキラリティを埋めれば「上下左右・表裏」を一意に決められる。
  → QR の 3-finder L 字(非対称)と同じ目的を、生物的モチーフで自然に達成。
- **主溝/副溝 = 二つの読者経路**: 表(誰でも検証=L3)を一方の溝に、裏(発行者だけ=柱6 潜在=L2)を
  もう一方の溝に。人は「らせんの絵」(L1)を見る = 3 読者(人/AI/発行者)の役割分担 = 調和。
- **塩基対合則 = 制約アルファベットによる誤り検出**: 許される対合(A-T/G-C)以外が出たら破損のサイン
  = アルファベットに焼き込んだ checksum。RS の手前で「明らかな読み違い」を弾く軽量層。
- **ひねりの周期 = 自己クロック(timing pattern)** ← ✅ 実装済(2026-06-06・`src/photo.js` §5.12)。
  データを囲む分離リングに交互の黒モジュール(tick 列)を並べ、復号時に **プラムライン法**(=直線は
  undistort 後も直線)で**放射状レンズ歪み**(ホモグラフィでは表せない曲がり)を推定して補正する。tick の
  間隔(2 モジュール)が**真の尺度参照**になり finder 面積由来の N 誤りも消す。糸巻き +0.3 / 樽 -0.15 まで復元。
- 非目標(予防線): 「美しいらせんの見た目」を先にやらない。まず素朴な格子で一周(image.js/photo.js)を
  通し済み。らせんは**有機担体 L1/L2 の具体案**であり、約束の層は一切いじらない。

## 4. その他の対応(完全性のための索引)

| 生物の機構 | 柱 | 一言 |

> 能力超過を**検出して安全に失敗**する設計(ImageCarrierError/PhotoError)は、この正直さと整合。
